# VideoCompare

VideoCompare 是一个面向画质、机位和视频版本对比的 macOS 本地桌面工具。它的核心目标是让两路高分辨率视频可以在同一个窗口内高性能播放、逐帧对齐和快速切换观察差异，优先服务 4K 60fps x2 的对比场景。

## 核心功能

### 视频加载和播放管线

- A/B 两路视频分别加载，支持文件选择、Finder 拖入和已挂载的 SMB 网络盘路径。
- 支持 `mp4`、`mov`、`mkv`，面向 H.264/H.265 硬解码播放；暂不以 HDR/BT.2020 为目标。
- 使用 FFmpeg 解封装、VideoToolbox 硬解码、Metal 合成渲染，两路视频始终在同一个 app 窗口内显示。
- 默认不加载字幕，播放菜单中可切换。

### 对比模式

- **左右对比**：A/B 分别显示在左右两侧，适合检查构图、清晰度、曝光、颜色和局部细节差异。此模式下不应用画面平移/缩放，确保两路视频以默认方式并排比较。
- **拖动遮罩**：A/B 叠在同一画布上，通过竖向分界线决定左右两边分别显示哪一路。分界线可鼠标拖动，用于快速扫过画面边缘、纹理、动态范围和算法差异。
- 拖动遮罩模式下按 `Tab` 会把分界线切到最左或最右，相当于在全屏 A 和全屏 B 之间切换，替代原来的点击切换模式。
- 拖动遮罩模式下可选中 A 或 B 后拖动画面位置，或用 `Option` 拖动 / `Cmd` 滚轮连续缩放，以补偿机位差异，让两路内容在同一画面区域对齐。

### 播放控制

- 底部同步进度条控制两路视频的共同时间基准，支持同步播放/暂停、同步 seek、同步上一帧/下一帧。
- 左右对比模式下，每路视频区域内各有独立进度条，可单独 seek A 或 B，用于手动建立两路视频之间的帧级时间差。
- 选中 A/B 后，方向键上一帧/下一帧只作用于该路视频，并把调整结果写入两路之间的帧数 diff；未选中时方向键执行同步逐帧。
- 空格键遵循同样的选中逻辑：未选中时控制同步播放/暂停，选中 A/B 时按当前布局规则控制对应播放行为。
- 时间长度不同的情况下，超出内容范围的一侧显示黑屏，另一侧仍可继续按同步时间基准播放或 seek。

### 片段循环和状态记忆

- 同步进度条支持 `Cmd` + 鼠标横向拖选一个片段，之后同步播放会在该片段范围内循环。
- 右键点击已选片段可取消循环；同一时间只支持一个循环片段，新选择会替换旧选择。
- 按视频组合记忆帧数 diff，重新打开同一组视频时可以恢复时间对齐关系。
- 画面平移和缩放只在当前会话内生效，不按视频组合持久化。
- 支持最近视频组，方便重复打开常用 A/B 组合。

## 快捷键

- `1` / `2`：选择视频 A / B。
- `Cmd+1` / `Cmd+2`：切换左右对比 / 拖动遮罩。
- `Tab`：在拖动遮罩模式下将分界线切到最左或最右。
- `←` / `→`：未选中视频时同步上一帧/下一帧；选中 A/B 时只调整对应视频，并更新帧数 diff。
- `Space`：未选中视频时同步播放/暂停；选中 A/B 时按当前布局规则控制播放。
- `Esc`：取消当前选中视频。
- `Cmd+W` / `Cmd+Q`：关闭/退出应用。

## 构建和运行

```bash
./scripts/build_app.sh
open dist/VideoCompare.app
```

项目使用 Swift Package Manager 构建。当前本机依赖 Homebrew 安装的 FFmpeg 和 mpv 开发库：

```bash
brew install ffmpeg mpv
```

构建脚本会生成：

```text
dist/VideoCompare.app
```

## 当前限制

- 只面向本地运行，没有签名、安装器或自动更新流程。
- SMB 路径需要先由系统/Finder 挂载后再选择或拖入。
- 拖动实时 seek 已按帧级目标处理，但精确 seek 仍受 GOP、编码结构、网络 I/O 和双路硬解成本影响。
- HDR、BT.2020、旋转校正和字幕渲染不在当前范围内。
