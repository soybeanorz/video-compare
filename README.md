# VideoCompare

VideoCompare 是一个面向画质、机位和视频版本对比的 macOS 本地桌面工具。它的核心目标是让两路高分辨率视频可以在同一个窗口内高性能播放、逐帧对齐和快速切换观察差异，优先服务 4K 60fps x2 的对比场景。

## 核心功能

### 视频加载和播放管线

- A/B 两路媒体分别加载，支持文件选择、Finder 拖入和已挂载的 SMB 网络盘路径；一次拖入 2 个受支持文件时会按顺序加载到 A/B。
- 支持拖入目录到文件面板：单个目录会同步加载到 A/B 文件面板，两个目录会分别加载到 A/B；目录只作为浏览根目录，不会自动加载目录内视频。
- 视频支持 `mp4`、`mov`、`mkv`，面向 H.264/H.265 硬解码播放；照片支持 `jpg`、`jpeg`、`png`、`heic`、`heif`、`tif`、`tiff`、`bmp`、`gif`、`webp`、`dng`。暂不以 HDR/BT.2020 为目标。
- 使用 FFmpeg 解封装、VideoToolbox 硬解码、Metal 合成渲染，两路视频始终在同一个 app 窗口内显示。
- 默认不加载字幕，播放菜单中可切换。

### 对比模式

- **并排对比**：A/B 分别显示在左右两侧，适合检查构图、清晰度、曝光、颜色和局部细节差异。此模式下不应用画面平移/缩放，确保两路视频以默认方式并排比较。
- **滑动对比**：A/B 叠在同一画布上，通过竖向分界线决定左右两边分别显示哪一路。分界线可鼠标拖动，用于快速扫过画面边缘、纹理、动态范围和算法差异。
- 按 `Cmd+B` 或点击右上角文件面板按钮，可在对比模式切换控件下方展开/收起 A/B 双文件浏览器；收起时保留可编辑路径栏，已加载媒体时显示完整文件路径，否则显示 Home 目录。浏览器只列出文件夹和受支持媒体文件，展开后支持列表/图标视图和按名称、修改时间、类型排序；双击文件会加载到对应窗口，也可拖动文件到任意窗口加载。
- 右上角 `?` 可打开操作说明。说明面板按操作类型分组展示快捷键和功能。
- 滑动对比模式下按 `Tab` 会把分界线切到最左或最右，相当于在全屏 A 和全屏 B 之间切换，替代原来的点击切换模式。
- 滑动对比模式下可通过拖动和滚轮调整画面位置/缩放，以补偿机位差异：默认拖动或滚轮会同步作用于 A/B，按住 `Cmd` 时只作用于鼠标所在一路。
- 滑动对比模式下支持手动 ROI 自动对齐：暂停时按 `Ctrl` 拖动画面框选一个可匹配区域，系统会在另一侧当前帧中搜索匹配区域，并把两侧 ROI 聚焦到画面中心、分界线回中。

### 预览调色和画面辅助

- 按 `Opt+Cmd+C` 可打开当前选中视频的调色面板。调色只影响预览，不修改源文件、不导出、不持久化。
- 调色面板支持曝光、对比度、亮度、饱和度、色温、色调、清晰度/锐化，以及带直方图背景的亮度曲线调整。
- A/B 各有独立的会话内调色参数；切换选中视频后，面板会控制当前选中的一路。
- 按住 `O` 可临时查看选中视频的原始画面，松开后恢复调色效果。
- 按 `F` 可在 A/B 画面左上角显示或隐藏当前帧序号。
- 画面拖动、缩放、调色调整和 ROI 自动对齐支持 `Cmd+Z` 撤销、`Cmd+Shift+Z` 重做。

### 播放控制

- 底部同步进度条控制两路视频的共同时间基准，支持同步播放/暂停、同步 seek、同步上一帧/下一帧。
- 并排对比模式下，每路视频区域内各有独立进度条，可单独 seek A 或 B，用于手动建立两路视频之间的帧级时间差。
- 选中 A/B 后，方向键上一帧/下一帧只作用于该路视频，并把调整结果写入两路之间的帧数 diff；未选中时方向键执行同步逐帧。
- 空格键遵循同样的选中逻辑：未选中时控制同步播放/暂停，选中 A/B 时按当前布局规则控制对应播放行为。
- 时间长度不同的情况下，超出内容范围的一侧会保持第一帧或最后一帧，另一侧仍可继续按同步时间基准播放或 seek。

### 片段循环和状态记忆

- 同步进度条支持 `Cmd` + 鼠标横向拖选一个片段，之后同步播放会在该片段范围内循环。
- 右键点击已选片段可取消循环；同一时间只支持一个循环片段，新选择会替换旧选择。
- 按视频组合记忆帧数 diff，重新打开同一组视频时可以恢复时间对齐关系。
- 画面平移和缩放只在当前会话内生效，不按视频组合持久化。
- 调色参数和 ROI 自动对齐结果也只在当前会话内生效。
- 支持最近视频组，方便重复打开常用 A/B 组合。

## 快捷键

- `1` / `2`：选择视频 A / B。
- `Cmd+1` / `Cmd+2`：切换并排对比 / 滑动对比。
- `Cmd+B`：展开/收起文件面板。
- `Tab`：在滑动对比模式下将分界线切到最左或最右。
- `←` / `→`：未选中视频时同步上一帧/下一帧；选中 A/B 时只调整对应视频，并更新帧数 diff。
- `Space`：未选中视频时同步播放/暂停；选中 A/B 时按当前布局规则控制播放。
- `Esc`：取消当前选中视频。
- `F`：显示/隐藏当前帧序号。
- `O`：按住查看选中视频的原始画面。
- `Opt+Cmd+C`：打开选中视频的调色面板。
- `Drag`：滑动对比模式下同步拖动 A/B 画面。
- `Cmd+Drag`：滑动对比模式下只拖动鼠标所在画面。
- `Scroll`：滑动对比模式下同步缩放 A/B 画面。
- `Cmd+Scroll`：滑动对比模式下只缩放鼠标所在画面。
- `Ctrl+Drag`：滑动对比模式下框选 ROI 并自动对齐。
- `Cmd+Z` / `Cmd+Shift+Z`：撤销/重做画面预览调整。
- `Cmd+W` / `Cmd+Q`：关闭/退出应用。

## 构建和运行

```bash
./scripts/build_app.sh
open dist/VideoCompare.app
```

项目使用 Swift Package Manager 构建。当前本机依赖 Homebrew 安装的 FFmpeg 开发库：

```bash
brew install ffmpeg
```

构建脚本会生成：

```text
dist/VideoCompare.app
```

## 当前限制

- 只面向本地运行，没有签名、安装器或自动更新流程。
- SMB 路径需要先由系统/Finder 挂载后再选择或拖入。
- 拖动实时 seek 已按帧级目标处理，但精确 seek 仍受 GOP、编码结构、网络 I/O 和双路硬解成本影响。
- ROI 自动对齐只处理平移和小范围尺度差异，不处理旋转、透视、形变或时间同步；低纹理或不相似区域可能无法可靠匹配。
- HDR、BT.2020、旋转校正和字幕渲染不在当前范围内。
